# ScheduleParser

Консольная утилита на .NET 8 для поиска занятий преподавателя в **листах замен** учебного заведения. Читает Excel-файлы `.xlsx` и `.xls` из папки и всех вложенных папок, формирует единый `.xlsx`-отчёт.

## Как работает

1. Ищет файлы с ключевыми словами `лист замен` (учитывает различия в регистре и повторные пробелы). Файлы «занятость» по умолчанию не участвуют.
2. Находит строку заголовков и **определяет столбцы по их названиям**, а не по фиксированным буквам. Поддерживает шаблоны, где дисциплина находится в `B` или `E`, преподаватель в `E` или `H`, аудитория в `F`, `G` или `I`.
3. Читает группу из строки-разделителя (`1-26 ИСП-1`), а занятия из строк с номером пары. Для объединённых по вертикали ячеек учитывает содержимое исходной ячейки.
4. Сопоставляет фамилию или ФИО преподавателя без учёта регистра; `ё` и `е` считаются эквивалентными. Сравнивает **границы слова**, чтобы «Иванов» не находился внутри «Иванова».
5. Дату берёт в первую очередь из заголовка/параметров самого листа; если там нет даты — из имени файла. При расхождении сообщает об этом.
6. Удаляет одинаковые занятия из повторно выгруженных файлов (`(1)`), сортирует по дате, паре и группе, сохраняет таблицу с источником и номером исходной строки.

## Сборка

Требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

```powershell
dotnet restore
dotnet build -c Release
dotnet test -c Release
```

## Использование

**Интерактивно**:

```powershell
dotnet run --project ScheduleParser
```

Программа предложит указать: папку расписания, фамилию или ФИО, ключевое слово файла (по умолчанию `лист замен`), папку для отчёта.

**Без вопросов, четырьмя аргументами**:

```powershell
dotnet run --project ScheduleParser -- "D:\Расписание" "Иванов" "лист замен" "D:\Отчёты"
```

**Результат**: файл `outputdd_MM_yy_HH_mm_ss.xlsx` в указанной папке. В таблице есть: дата, номер пары, учебная группа, подгруппа, дисциплина, преподаватель, аудитория, территория, исходный файл, исходный лист и номер строки Excel.

При нуле совпадений создаётся корректный отчёт с заголовками, без исключения. Ошибки чтения отдельных файлов выводятся в `stderr`: остальные документы продолжают обрабатываться.

Коды завершения: `0` — без предупреждений, `1` — некорректные параметры или ошибка сохранения, `2` — отчёт создан, но при чтении отдельных документов обнаружены предупреждения.

## Ограничения

- Предполагается структура листа замен: заголовки `Номер пары`, `Дисциплина`, `Преподаватель` и строки групп вида `1-26 ИСП-1`. Файл с другой структурой не обрабатывается, о нём выводится предупреждение.
- Не производится восстановление полного расписания из графика «занятости преподавателей»: это другой тип исходных данных.
- Для конфликтующих дубликатов (`(1)` с исправленными данными) **разные** занятия остаются в отчёте, чтобы исправления не скрывались автоматически. Проверяйте конфликтующие записи вручную.
- Не включайте в публичные тесты реальные персональные данные преподавателей и студентов без соответствующего разрешения.
