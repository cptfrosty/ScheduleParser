# ScheduleParser
Инструмент разработан для личного удобства. Это не универсальный парсер, а лишь для конкретной задачи и структуры excel файла.

![alt text](https://github.com/cptfrosty/ScheduleParser/blob/main/Screenshots/Screenshot_1.png)

## Запуск приложения
Шаг 1. Запустите ScheduleParser.exe

Шаг 2. Введите необходимые данные

Шаг 3. Приложение выдаст найденые занятия преподавателя в консоли и сформирует excel файл для дальнейшей работы

## Примерные данные

Тестовые данные можно посмотреть в папке ExampleShedule

Входные данные: 
```
(1/4 шагов) Введите путь к папке с excel расписанием:
D:\projects\ScheduleParser\ExampleShedule

(2/4 шагов) Введите искомую фамилию:
Дмитриев

(3/4 шагов) Введите ключевое слово в названии файла:
лист замен

(4/4 шагов) Введите путь для сохранения результатов:
D:\projects\ScheduleParser\ExampleShedule\results
```
